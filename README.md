\# ChronoRx: Circadian Pharmacodynamics Engine



ChronoRx is a clinical decision support (CDS) application that aligns medication dosing schedules with endogenous 24-hour circadian rhythms to maximize therapeutic efficacy and mitigate timing-induced toxicities.



\## Clinical Scope

\- \*\*HMG-CoA Reductase Inhibitors (Simvastatin):\*\* Nocturnal target synchrony.

\- \*\*RAAS Blockers (Ramipril/Telmisartan):\*\* Blunting nocturnal non-dipping cardiovascular risk.

\- \*\*Glucocorticoids (Prednisolone):\*\* HPA axis preservation aligned with morning cortisol acrophase.

\- \*\*Thyroid Hormones (Levothyroxine):\*\* Fasting absorption window optimization.
